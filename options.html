Send Link to SwarmUI

Right-click anything on a web page and choose Send to SwarmUI. If clicked on a link, its href is sent; otherwise the current page URL is sent. The extension opens/reuses one target page to navigate to: server-url/Text2Image?downloader=1&url=ENCODED_SOURCE_URL If you omit a scheme, http:// is assumed. When popup mode is enabled, first-open uses a popup window and reuses that same tab for later sends.
